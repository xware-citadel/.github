# XWare Citadel



**Technical portfolio focused on AI-powered systems and modern backend architecture.**

We design and build production-oriented solutions that integrate Large Language Models, autonomous agents, and computer vision into real business workflows.

### Focus Areas

- AI Agents & Multi-agent systems
- RAG (Retrieval-Augmented Generation) architectures
- Backend systems (FastAPI, Go, Node.js)
- Computer Vision solutions
- System design, scalability, and production readiness

### What you'll find here

Each repository contains:

- Clear problem statement
- Architecture decisions and trade-offs
- Database and system design
- Edge cases and how they are handled
- Scalability considerations
- Working demos where possible

These projects serve as deep technical explorations of common business challenges. The approaches, patterns, and decisions demonstrated here are the same ones we apply in client work.

### Tech Stack

- **Backend**: FastAPI, Go (Gin/Huma), Node.js
- **AI/ML**: LangChain, LlamaIndex, OpenAI, Anthropic, local models
- **Infrastructure**: Docker, PostgreSQL, Redis, Vector databases
- **Other**: Computer Vision pipelines, event-driven architectures
